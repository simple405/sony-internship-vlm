SECTION 2：状态约定
═══════════════════════════════════════════

- visible 字段只能是 "visible" 或 "invisible"，表示该特征是否出现在对应视角。
- status 字段表示呈现是否正确。
  - 当 visible="visible" 时，status 只能是："correct", "wrong color", "wrong material", "wrong shape", "extra"
  - 当 visible="invisible" 时，status 只能是："correct", "wrong invisible"
- 不要输出 "correct invisible"；如果预期不可见且确实不可见，使用 status="correct"。
- result：如果没有任何 status 错误则为 "correct"；只要任一 status 是错误类型则为 "wrong"。

SECTION 5：PVC 材质判断口径
═══════════════════════════════════════════

PVC 手办与布偶不同，不存在织物纹理。在判断材质时注意：
- 材质只判断大类（塑料/金属/布料）；手办整体为硬质塑料是正常的，不要因为"没有布料质感"判 wrong material。
- 金属配件（如扣件、武器）在手办中通常也是塑料涂装，如果颜色正确则不算 wrong material。
- 透明零件（如斗篷、翅膀）在手办中常见，如果源图有透明感应判断是否有对应透明材质处理。

═══════════════════════════════════════════
SECTION 6：颜色、形状判断口径
═══════════════════════════════════════════

- 只对颜色、形状/结构的大类明显错误判 wrong。
- 相近色、光影、高光、涂装光泽导致的色差不算 wrong color。
- 相近色按同一大类处理：红/粉/玫红/红棕，紫/淡紫/粉紫/浅粉/淡粉，蓝/青/蓝绿，绿/黄绿，金/黄/金发，白/银/浅灰，黑/深灰/深蓝黑，棕/红棕/深棕/卡其/驼色。
- 形状只判断稳定结构大类：长短发、衣服版型、鞋型、领型、帽型、发型结构；不要因局部造型、姿态、透视或细碎线条判 wrong shape。
- PVC 手办的比例可能因立体化与原 2D 图有轻微差异（如头身比、腿部拉伸），这是立体化正常结果，不算 wrong shape。

SECTION 7：判断流程
═══════════════════════════════════════════

对每条 atomic rule 按顺序执行：
1. 是否是手办未持有的手持道具规则（has_bag, bag_color）？如果是，三视角全部 invisible + correct。
2. back 视角：所有规则统一输出 back_visible="invisible", back_status="correct"。
3. side 视角：除非元素明显从正面延伸至侧面，否则统一输出 side_visible="invisible", side_status="correct"。
4. front 视角：该特征是否出现在手办正面渲染图中？
   - 如果可见，与源图比较颜色/形状：correct / wrong color / wrong shape / extra。
   - 如果不可见，判断是否应可见：应可见而缺失 → wrong invisible；本来就不可见 → invisible + correct。
5. 任何视角有错误则 result="wrong"，否则 result="correct"。
