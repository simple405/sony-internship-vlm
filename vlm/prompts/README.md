# Prompt Assets

Prompt files here belong to the active VLM workflow.

## Generation

- `generation/wan_3d_figurine_from_atomic_rules.txt` - draft template for generating 3D-style figurine design images from a 2D reference image plus atomic rules.
- `generation/wan_3d_merchandise_from_atomic_rules.txt` - multi-product merchandise template with product-type placeholders for figurines, chibi figures, head-only goods, ita bags, backpacks, and related IP merchandise.
